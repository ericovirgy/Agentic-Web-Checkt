# Product Hunt (prepared, not submitted, not recommended now)

Source: https://www.producthunt.com/launch and /launch/launch-guide, read via a summarising fetcher.
Facts: personal accounts only, no direct upvote requests, self-hunting allowed, open source is fine
if the licence is respected, categories exist for Engineering and Development and for AI Agents.
2026-specific requirements were not found in a primary source.

## Recommendation

Do not launch there in the first two weeks. Reason: a launch without an existing audience brings
little traction, and the product is a CLI whose strongest proof is a terminal session, which suits
Hacker News and developer newsletters better. Revisit after a benchmark or after at least a few
real external users exist. Alternative with fewer barriers: DevHunt (free queue, accepts CLIs and
open source), later.

## Prepared listing (if it is revisited)

- Name: Agentic Web Check
- Tagline (max 60): Test whether AI agents can really use your website
- Description (max 260): Open-source CLI that loads your site in headless Chromium, runs 43 checks and read-only tasks, and shows where an AI agent gets stuck. Verdicts come from assertions on the final page. No API key for the default mode, no telemetry. MIT.
- Topics: Developer Tools, Open Source, Artificial Intelligence, Accessibility

- Gallery: terminal report image (fixture, labelled), HTML report screenshot, 30 to 45 second screen recording of the one-command run

## Do not

Ask for upvotes, create extra accounts, use an agency, or claim traction.
