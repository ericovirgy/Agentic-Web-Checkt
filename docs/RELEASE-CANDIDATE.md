## npm publishing method

npm Trusted Publishing (GitHub Actions OIDC) in `.github/workflows/release.yml`: `permissions: id-token: write`, `npm install -g npm@^11.5.1`, `npm publish --access public --tag latest|next`, no `NODE_AUTH_TOKEN`, no `NPM_TOKEN` secret anywhere; provenance is generated automatically for the public repository and package (`publishConfig.provenance: true` is kept). `workflow_dispatch` runs the whole workflow in dry-run mode (tests, build, pack, `npm publish --dry-run`) and skips the publish, the GitHub release and the tag move; executed on the runner: runs 37271344638 and 37271770426, both green.
